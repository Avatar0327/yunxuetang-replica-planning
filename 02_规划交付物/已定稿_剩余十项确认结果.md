## B 类：建议的有意差异（4 项）

### ① DIFF-02 兼职部门不计入部门统计
| | |
|---|---|
| **原站行为** | 「部门人数：当前部门下的人数，**不包含兼职人员**」；人员是 1 主部门 + N 兼职部门 |
| **我的处置** | 沿用原站——**只按主部门统计** |
| **代价/风险** | 若你们大量使用兼职部门（如矩阵式组织、借调），**兼职部门负责人在报表里看不到借调过来的人**。原站也是这样，但如果这是你们的真实场景，值得改。 |
| **改的成本** | 统计层增加"是否含兼职部门"开关，约 +2~3 人天 |

### ② DIFF-06 看板排除停用人员，明细可查
| | |
|---|---|
| **原站行为** | 数据大屏硬性「仅统计启用人员」；报表中心人员状态**可筛选**（启用/禁用/删除） |
| **我的处置** | 沿用这个分层设计，**但要求看板标题处注明"仅统计在职人员"** |
| **代价/风险** | 低。这本身是合理设计（我最初误判为缺陷，后来收回） |
| **备注** | 加注明是我加的要求，原站没有 |

### ③ DIFF-18 活跃时长不足 1 分钟按 1 分钟计
| | |
