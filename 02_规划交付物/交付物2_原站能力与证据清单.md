# 六、调研方法与限制

## 方法
1. 先建全站模块与路由地图（E004），再选核心闭环深入。
2. 优先**纯只读取证**：配置表单打开即可见全部字段与规则选项，无需提交。
3. 最小写仅用于**无替代手段**的验证（学习闭环 W-h、考试规则 W-f）。
4. 所有规则优先采用**原站原文说明**（指标浮层、字段提示、弹窗文案），而非界面推断。

## 限制
1. **单一身份**：全程仅 admin 一个账号，无法做多角色对照（G-01~G-04）。
2. **单日窗口**：2026-09-21 一天完成，无法验证跨日行为（T-1 统计、每日扫描、V-48 复查）。
3. **演示数据**：租户为演示环境，数据量与真实业务不符；所有项目/考试均处「未发布」状态，无法观察运行态行为。
4. **视口限制**：浏览器面板宽度小于应用最小宽度 1280px，部分宽表格需横向滚动，可能遗漏右侧列。
