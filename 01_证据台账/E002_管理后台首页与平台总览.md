## 5. 空值语义【已验证】——直接回应「区分未配置/空值/0」
同一看板内**同时出现 `--` 与 `0` / `0%` 两种表示**：
- 计数类指标无数据时显示 `--`（项目总量、考试总量等）
- 比率类指标无数据时显示 `0%`（学习率、完成率、考试通过率）
- 而课程区的计数类指标显示 `0`（学习人次 0、完成人次 0）

**【已验证】结论**：`--` 与 `0` 在原站是**不同语义**——`--` 表示无数据/不适用，`0` 表示有统计但值为零。
**【未验证】**：比率类在分母为 0 时显示 `0%` 而非 `--`，属于口径不一致（分母为 0 时通过率本应无意义）。
**规划建议**：目标产品应统一为「分母为 0 时比率显示 `--`」，避免把「无人参考」误读为「通过率 0%」。此项列入**差异清单 DIFF-01（建议有意差异，不复刻原站缺陷）**。
