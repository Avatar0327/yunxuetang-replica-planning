## 3. ⭐ 培训规划的数据模型【已验证】

```
培训计划 Plan
├─ 身份：计划名称、计划编号(≤20)
├─ 分类：计划类别(年度/季度/月度/临时) + 计划年度
├─ 时间：计划时间(起止) + 「计划延期支持创建项目」开关
├─ 责任：实施部门、负责人
├─ 目标：计划培训人数            ← 计划值
├─ 资源：计划预算(开关)、计划资源(开关)
└─ 实施活动 Activity[]  ≤50
     ├─ 培训项目 Project   （引用 或 直接创建）
     ├─ 外训 ExternalTrain （引用 或 直接创建）
     └─ 面授 OfflineTrain  （引用 或 直接创建）
```

### 规划含义（重要）
1. **培训计划是"计划层"，项目/面授/外训是"执行层"** —— 二者是 1:N 关系，且执行层对象**可以脱离计划独立存在**（实测 8 个项目均未关联计划）。
   → **目标产品不应强制项目必须归属计划**。
2. **「计划培训人数」是计划值，与实际参训人数分离** —— 这是培训规划模块存在的核心意义：**计划 vs 实际的对比**。
   → 报表需支持 `计划完成率 = 实际 / 计划`（呼应 E013 §9 的「培训计划统计 → 计划完成情况」）。
3. **外训是与项目、面授并列的第三类执行对象**（E004 中的「外派培训」），批次 8 若做培训规划，**外训对象需一并纳入**，否则活动类型不完整。
   → ⚠️ **这是对批次 8 范围的修正**：原定"培训规划+面授+调查"，实际还需**外训**。列为 **V-59**，工作量需相应上调。
